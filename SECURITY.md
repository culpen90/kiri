# Security

Use the [Security tab](https://github.com/stowlark/stowlark/security) to report a vulnerability privately when private reporting is available. Avoid sharing credentials, chat content, or personal data in a public issue.

Include the app version, Android version, and affected feature. For issues involving Linux tool approval or the guest environment, include the Stowlark launcher version and describe the behavior you observed. See the [Stowlark runtime security policy](runtime/SECURITY.md) and [Android trust model](runtime/docs/android.md#trust-model) for runtime details.
