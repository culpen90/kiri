# Contributing to AnythingLLM Mobile

See the [development guide](DEVELOPMENT.md) to set up the Android app. For changes to the Stowlark Linux runtime, see [runtime/CONTRIBUTING.md](runtime/CONTRIBUTING.md).

Before making a larger change, open an issue to discuss the approach. Keep each pull request focused and sign your commits.

Run `yarn translations:verify`, `yarn lint`, `yarn typecheck`, and `yarn test --runInBand` from the repository root. For behavior changes, describe what you tested on Android and include the device model and Android version.
